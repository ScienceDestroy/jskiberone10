# Урок 10 — Игра-лабиринт на Canvas

Код из урока 10 (тема: «Создание игр с использованием возможностей языка
JavaScript по взаимодействию с элементом HTML Canvas»).

## Файлы

| Файл | Что внутри |
|------|------------|
| `index.html` | HTML: canvas, кнопки управления, подключение стилей и скрипта |
| `style.css` | CSS: рамка и фон игрового поля |
| `scripts.js` | JavaScript: игровая логика (фигура, препятствия, столкновения, победа) |
| `all-in-one.html` | Всё в одном файле — можно открыть двойным щелчком |

## Как запустить

**Вариант 1 — три файла.** Все три файла должны лежать в одной папке.
Откройте `index.html` в браузере.

**Вариант 2 — один файл.** Откройте `all-in-one.html` в браузере.

**Вариант 3 — jsfiddle.net.** Скопируйте:
- HTML из `index.html` (без строки `<script src="scripts.js"></script>`) — в панель HTML;
- CSS из `style.css` — в панель CSS;
- JS из `scripts.js` — в панель JavaScript.

## Управление

Синий квадрат двигается кнопками **Вверх / Налево / Направо / Вниз** по одному
пикселю за нажатие. Красные, зелёные, жёлтые и розовые полосы — стены лабиринта.
При столкновении появляется сообщение «Вы врезались в препятствие!», и фигура
возвращается в начало. Серый квадрат справа — финиш: при входе в него появляется
«Вы победили!», и игра начинается заново.

## Что пришлось поправить по сравнению с PDF

В методичке код напечатан с парой опечаток и в невалидной разметке. В файлах
исправлено:

1. `<canvas>` стоял **до** открывающего `<body>` — перенесён внутрь `body`.
2. В задании было `<bode onload=“game()>` — исправлено на `<body onload="game()">`.
3. Стили canvas вынесены в `style.css`, убран дублирующий `style` у `<canvas>`.
4. Скрипт подключён в конце `<body>`, чтобы `game()` гарантированно нашёл canvas.

Сама игровая логика оставлена как в уроке.

## Как это работает

- `figure()` — «класс» игрока: хранит `x`, `y`, `width`, `height`, умеет
  перерисовываться (`update`) и проверять столкновения (`crashEx`).
- `obstacle(x, y, width, height, color)` — «класс» стены, рисует себя на canvas.
- `make_obstacles()` — создаёт массив `obstacles` из семи стен.
- `update()` — очищает поле, рисует стены, финиш и игрока, проверяет столкновения
  и победу.
- `game()` привязана к `onload` элемента `body`, поэтому запускается сразу после
  загрузки страницы.

## Задание для самостоятельной работы

Сделать собственный уникальный лабиринт: изменить расположение, размеры и цвета
стен, размер поля и шаг фигуры (например, двигать не на 1, а на 5–10 пикселей),
добавить свои препятствия. Дополнительно можно поменять финишный квадрат и текст
поздравления.
